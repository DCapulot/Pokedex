# Pokédex

Uma Pokédex web feita com HTML, CSS e JavaScript puros, para consultar informações de Pokémon direto no navegador.

🔗 **Demo online:** [dcapulot.github.io/Pokedex](https://dcapulot.github.io/Pokedex/)

---

## Sobre o projeto

Este projeto é uma Pokédex interativa, sem frameworks nem dependências externas para instalar. Basta abrir o `index.html` no navegador para usar. Foi criado para praticar manipulação do DOM, consumo de dados e estilização responsiva com CSS.

## Funcionalidades

- Listagem de Pokémon com imagem, nome e número
- Busca por nome ou número
- Exibição de detalhes (tipos, altura, peso, habilidades e status)
- Layout responsivo para desktop e celular

## Como executar

### Online

Acesse: https://dcapulot.github.io/Pokedex/

### Localmente

```bash
# 1. Clone o repositório
git clone https://github.com/DCapulot/Pokedex.git

# 2. Entre na pasta
cd Pokedex

# 3. Abra o index.html no navegador
```

Se preferir um servidor local:

```bash
# com Python
python -m http.server 8000
# depois acesse http://localhost:8000
```
